# 简道云「WMS」模板分析

> 来源：简道云方案中心 WMS 模板说明页 + 官方使用手册（hc.jiandaoyun.com/solution/19708）
> 分析日期：2026-09-11
> 结论：**它的"WMS"实际上是进销存系统，不是真正的 WMS——但对你有重要的参考价值**

---

## 一、它的真实结构（来自官方使用手册）

```
1. 产品简介
2. 准备工作
   2.1 组织权限配置
   2.2 数据初始化（产品/仓库/客户/供应商）
   2.3 数据工厂同步（期初期末库存）
3. 详细步骤
   3.1 销售管理          ← 3 个功能
       销售订单 / 销售出库 / 销售退货
   3.2 采购管理          ← 3 个功能
       采购订单 / 采购入库 / 采购退货
   3.3 库存管理          ← 4 个功能
       其他入库单 / 其他出库单 / 库存调拨 / 库存盘点
```

---

## 二、⭐ 重大发现：它的"WMS"其实是进销存

**10 个业务功能里，6 个是销售 + 采购**（ERP 职责），只有 4 个是库存相关。

而且这 4 个库存功能是：其他入库单、其他出库单、库存调拨、库存盘点——**全部是"记账"性质**。

**它完全没有真正的仓内作业功能**：

| 真正的 WMS 该有 | 简道云模板有吗 |
|---|---|
| 货位主数据（A01-03-02） | ❌ 无 |
| **货位分配（上架推荐）** | ❌ 无 |
| 拣货任务生成 | ❌ 无 |
| **拣货路径优化** | ❌ 无 |
| 波次拣货 | ❌ 无 |
| 收货→质检→上架流程 | ❌ 无 |
| ABC 分类 / 频繁度分析 | ❌ 无 |
| 智能补货决策 | ❌ 无 |

**它做的只是"哪个仓有多少货"，而不是"货在仓里的哪个位置、怎么搬"。**

> 换句话说：**它是 ERP 的库存模块，挂了个 WMS 的名字。**

---

## 三、这对你意味着什么（好消息）

### ① 验证了"不要照抄"的警告

如果你照着这个模板做，做出来的**是一个进销存系统，不是 WMS**——正好踩中你设计文档否定的"大而全的增删改查"。

### ② 你的项目比它的"WMS"更像 WMS

你有的东西，它一样都没有：

| 你有 | 它没有 |
|---|---|
| 1584 个真实货位 + 坐标 | ❌ |
| 货位分配算法 | ❌ |
| 拣货路径优化（三种策略对比） | ❌ |
| 波次合并 | ❌ |
| 需求预测 + 成本优化补货 | ❌ |
| 并发防超卖（技术深度） | ❌ |

**答辩时可以说**："我对比过市面上的零代码 WMS 模板，它们大多是进销存系统，**没有仓内作业能力**。我的项目聚焦真正的仓储作业——货位分配、拣货路径、波次拣货。"

## 四、✅ 值得学的 4 点

### 1. 数据初始化的标准流程（可照搬）

```
产品信息（属性、名称、分类）
仓库信息（名称、地址、主管）
客户 / 供应商信息
    ↓
数据量小 → 表单逐条录入
数据量大 → Excel 模板批量导入
```

**用到你的项目**：你的 1560 个商品、1584 个货位，也应该支持 **Excel/CSV 批量导入**——这本身就是个实用功能。

### 2. ⭐ "库存冻结"机制（重要，值得吸收）

它的销售出库有两种模式：
- **出库**：直接扣减库存
- **库存冻结**：**提前冻结库存，做"出库规划"，此时实际出库数为 0**

**这是个真实的业务设计**——解决"订单来了但货还没拣，期间库存被别的订单抢走"的问题。

**用到你的项目**：你的出库流程可以设计成两步：
```
① 出库单创建 → 冻结库存（可售库存 -N，实物库存不变）
② 拣货完成 → 扣减实物库存（冻结释放）
```
**这比"一步扣减"更真实，而且是个很好的面试展开点**（冻结超时释放、冻结与扣减的一致性）。

### 3. 业务联动的自动更新（主表-子表）

手册里反复出现："入库完成后，**自动将「采购订单」中入库状态、已入库数量、已入库成本总额做对应修改**"。

**用到你的项目**：入库单确认后，自动更新库存表 + 写入库存流水 + 更新单据状态——**一次操作，多处联动**。

### 4. 库存约束校验的业务表述

> "出库数量不能超过'待出库数量'和'当前可用库存数量'"

**这就是"防超卖"的业务语言版本**。你面试讲超卖时，可以先讲业务规则，再讲技术实现（乐观锁 + 分布式锁）。

---

## 五、❌ 不要学的 2 点

| 不学 | 原因 |
|---|---|
| **把销售、采购包进来** | ERP 职责；包进来就变进销存，失去 WMS 的聚焦 |
| **"万能模块清单"式设计** | 它要卖给各种企业所以全覆盖；你是单点突破，要**做深不做广** |

---

## 六、它的页面设计（供参考，未见到实际界面）

从说明页能推断出的页面类型：

| 页面类型 | 用途 |
|---|---|
| **经营看板** | 库存统计、出入库统计等可视化仪表盘 |
| **列表页** | 各单据的列表 + 筛选（销售订单列表、库存流水等） |
| **表单页** | 新建/编辑单据（含主表-子表） |
| **统计页** | 出入库统计、库存盘点对账 |

**对你的启发**：页面的三段式组织——**列表 → 表单 → 看板**（这也是简道云自己宣传的"界面→表单→流程→报表"）。

---

## 七、一句话总结

> **简道云的"WMS"是一套披着 WMS 外衣的进销存系统——它能告诉你 WMS 的"账"怎么做，但完全没回答 WMS 的"货怎么搬"。**
> **而这恰恰是你的机会：你的项目在这些模板的盲区里。**
