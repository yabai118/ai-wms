# wms-agent（Python 智能 Agent）

## 技术栈
FastAPI + SQLAlchemy（+ LLM API 作为后置加分项，可选）

## 负责的智能决策（切入仓储主流程）
1. 库存动态预测（指数平滑，输出补货建议）
2. 智能货位分配（评分函数：出库频率 × 重量 × 关联度）
3. 拣货路径优化（订单波次合并 + 贪心/最近邻）

## 与 Java 后端的交互
- 实时查询：RESTful API
- 异步计算：RabbitMQ 投递任务（如"入库后触发货位重算"）

## 降级约定
Agent 挂掉时，Java 后端降级为规则/人工分配，不影响出库主流程。
