# wms-backend（Java 后端底座）

## 技术栈
Spring Boot + MyBatis + MySQL + Redis + RabbitMQ（前端 Vue3，套现成 admin 模板）

## 负责的业务（高频事务 + 数据持久化 + 稳定性）
- 商品管理
- 入库（入库单 + 入库明细 + 库存增加，事务）
- 出库（出库单 + 出库明细 + 库存扣减，乐观锁 + 分布式锁）
- 库存（热点缓存 + 一致性）
- 货位管理（占用冲突检测）

## 模块边界（Day 1–2 细化 ER 图与接口契约）
- 不负责：财务、采购（那是 ERP 的事）
- 负责：仓库内部的"实物"与"作业"
