## 使用规则（重要，决定这个库有没有用）

1. **当天必须写**：学完一个知识点，当天用"自己的话"记下来，**不要抄我的原话**。
2. **一句话原则**：每个知识点最后必须写一句"我能怎么跟面试官讲"——写不出来 = 没学会。
3. **周末回填**：每周把 `每日学习/` 里的精华提炼进 `面试八股/`，冲刺期只看后者。
4. **踩坑必记**：当天 bug 卡了超过 10 分钟，就把"现象→原因→解决"写下来，这是你面试最真实的故事。

## 频率标注规则（每天的知识必须过这道筛子）

每个知识点我会标频率，你**只背 🔴 高频**，🟢 扫一眼即可：

- 🔴 **高频（必考必背）**：MySQL 索引/事务、Redis 缓存三大问题 + 一致性、并发锁/超卖、Spring IOC/AOP、网络 TCP/HTTP、JVM/Python 核心、MQ 可靠性、设计模式
- 🟡 **中频（熟悉会讲）**：MyBatis 缓存、动态 SQL、SQLAlchemy 细节等
- 🟢 **了解（知道即可）**：冷门参数、底层源码细节——面试几乎不考

**筛选三原则**：
1. 面试被问到的概率高 → 才教
2. 能被连环追问的 → 重点教（如 索引→B+树→最左前缀→回表）
3. 装 X 但没人问的 → 跳过（除非你主动问）
